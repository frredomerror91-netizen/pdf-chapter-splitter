# v1.5.0：大文件 OCR 更快，进度更清楚

这一版主要改善扫描版大文件的识别体验，减少开始识别前的等待，也更方便调整电脑的资源占用。

- **可以调整同时处理的分块数**：默认最多 4 个，也可以自己设置，或交给软件按电脑性能自动选择。
- **更早开始识别**：首个分块准备好就开始 OCR，不必等整本文件准备完。
- **进度显示更清楚**：可以看到文件准备、文字识别和分块完成情况。
- **中断后更方便继续**：重试时会复用仍然有效的分块和识别结果，减少重复处理。
- **改善部分 PDF 准备过慢的问题**：减少处理这些文件时的重复等待。

## 下载和使用

下载 `pdf-chapter-splitter-v1.5.0-source.zip` 并完整解压。需要 Windows、Python 3.10 或更高版本；安装依赖后，双击 `启动章节拆分工具.cmd` 启动。

```powershell
python -m pip install -r requirements.txt
```

扫描版需要另行安装 Umi-OCR，并在“OCR 设置”中选择主程序。识别时电脑比较卡，可以把并发上限改成 2 或 3；设为 0 时由软件自动选择。

升级时保留个人设置和识别缓存，可以继续使用原来的配置和未完成任务。识别完成后先核对章节标题与起始页，再导出。
