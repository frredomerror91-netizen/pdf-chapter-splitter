# v1.4.0：一键 OCR 与大型 PDF 并行处理

扫描版 PDF 可在工具内完成 OCR，再按章节导出。大型资料自动均匀分块，由最多两个独立引擎同时处理，完成后合并整本可搜索 PDF。

## 本版更新

- 100 页及以上自动分块，每块最多 50 页，按原页序合并。
- 大型 OCR 失败或取消后保留已完成块，重新执行可复用检查点。
- 正常持续处理时取消固定一小时总超时，改为无新增页面进度的停滞检查。
- 每次成功 OCR 在原文件旁保留 `<原文件名>_OCR.pdf`，后续章节分析失败也可继续使用。
- 新增暗夜模式和设置记忆。
- 修复页码书签、目录条目和重复页眉误识别，支持校对与手动编辑章节。

## 下载后使用

1. 下载并完整解压 `pdf-chapter-splitter-v1.4.0-source.zip`。这是源码包，需要 Windows 和 Python 3.10+。
2. 在项目目录运行 `python -m pip install -r requirements.txt`。
3. 双击 `启动章节拆分工具.cmd`，或执行 `python split_pdf_by_chapter.py`。
4. 扫描版另行下载并完整解压 Umi-OCR；在“OCR 设置”中选择 `Umi-OCR.exe`，默认本地服务地址为 `http://127.0.0.1:1224`。本版实际验证使用 Umi-OCR Rapid v2.1.5。
5. 选择 PDF，分析或一键 OCR，校对章节起始页，再导出。

源码包内含 README 和 `docs/使用说明.md`，覆盖首次安装、OCR 配置、分块恢复、保存位置、暗夜模式、升级和常见问题。

## 验证与使用范围

本版在 Windows 上通过 81 项回归测试及 Python 编译检查；发布用源码包另行检查文件内容和回归结果。并行提速取决于 CPU、磁盘和 PDF 内容，识别出的标题与章节边界需要校对。

Umi-OCR、模型、个人设置、教材 PDF 和 OCR 处理结果均不包含在源码包中。原始 PDF 保持不变。
