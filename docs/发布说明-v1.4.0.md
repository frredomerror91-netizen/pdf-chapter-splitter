# v1.4.0：扫描版也能一键按章拆分

这一版加入一键 OCR。选择扫描版 PDF 后，可以直接在工具里识别文字、查找章节，再按章导出，不用手动切换文件。

- **保留整本 OCR PDF**：识别完成后另存一份可搜索的文件，后续可以直接打开或再次分析。
- **支持大文件并行识别**：自动分块，由最多两个 OCR 引擎同时处理，最后按原顺序合并。
- **中断后可以继续**：失败或取消后保留已完成的分块，重试时减少重复识别。正常处理中的长任务也不会仅因超过一小时而停止。
- **增加暗夜模式**：可以切换主题，并记住主题和 OCR 设置。
- **改善章节识别**：减少把页码、目录条目和重复页眉认作章节的情况，仍可手动校对和修改。

## 下载和使用

下载 `pdf-chapter-splitter-v1.4.0-source.zip` 并完整解压。需要 Windows、Python 3.10 或更高版本；安装依赖后，双击 `启动章节拆分工具.cmd` 启动。

```powershell
python -m pip install -r requirements.txt
```

扫描版需要另行安装 Umi-OCR，并在“OCR 设置”中选择主程序。选择 PDF，分析或一键 OCR，核对章节标题和起始页，再导出即可。

原始 PDF 保持不变。OCR 结果会保存在原文件旁，文件名为 `原文件名_OCR.pdf`。
