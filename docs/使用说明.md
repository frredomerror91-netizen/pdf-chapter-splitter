# 使用说明

使用流程很简单：选择 PDF，识别章节，核对标题和页码，再导出。普通 PDF 可以直接分析；扫描版需要先配置 OCR。

## 首次安装

1. 从 [Releases](https://github.com/frredomerror91-netizen/pdf-chapter-splitter/releases) 下载源码 ZIP，并完整解压到普通文件夹。
2. 安装 Python 3.10 或更高版本，勾选“Add python.exe to PATH”，并保留 Tkinter 组件。
3. 在软件文件夹中打开 PowerShell，执行：

```powershell
python -m pip install -r requirements.txt
```

4. 双击 `启动章节拆分工具.cmd`，或在当前目录运行：

```powershell
python .\split_pdf_by_chapter.py
```

电脑上有多个 Python 环境时，安装依赖和运行软件要使用同一个环境。

## 配置扫描版 OCR

有文字或可靠章节书签的 PDF 可以先直接分析。扫描版、部分页面是图片或文字识别不准的资料，可以使用 OCR。

1. 下载并完整解压 [Umi-OCR 便携版](https://github.com/hiroi-sora/Umi-OCR/releases)，保留 `Umi-OCR.exe` 旁的 `UmiOCR-data` 文件夹。
2. 打开本工具的“OCR 设置”，选择 `Umi-OCR.exe`。
3. 在 Umi-OCR 中启用 HTTP 服务，设为“仅本地”。默认地址为 `http://127.0.0.1:1224`；改过端口时，两边保持一致。
4. 保存设置，然后选择 PDF，点击“一键 OCR 并分析”。

配置只需做一次。OCR 在本机运行，需要单独安装 Umi-OCR。

## 识别和校对章节

选择 PDF 后，按资料情况选择检测方式：

| 方式 | 适合的情况 |
| --- | --- |
| 自动（书签优先） | 通常选这一项，先找书签，再找页面标题。 |
| 仅 PDF 书签 | PDF 自带的章节目录准确完整。 |
| 仅页面标题 | 书签不可靠，但正文可以提取文字。 |
| 一键 OCR 并分析 | 扫描版、部分扫描页或需要重新识别文字的 PDF。 |

保留“无文字层时自动 OCR”时，自动检测模式下，如果整份 PDF 没有文字层，也没有可用的章节书签，会自动进入 OCR。

识别后，在表格中核对章节名称和起始页。双击可以修改，缺少的章节可以手动添加，多余的条目可以删除。封面、目录和前言通常会归入“前置内容”。

**页码从 PDF 的第一页开始计算。** 例如，书上印刷的第 1 页实际是 PDF 第 15 页，起始页就填写 15。上一章的结束页由下一章的起始页决定，最后一章一直到文件末尾。

核对完成后选择输出文件夹，点击“开始导出”，每章会生成一个 PDF。OCR 后导出的章节会保留文字层。

## 大文件和识别速度

达到 100 页的资料会自动分块识别，完成后按原顺序合并，不需要自己先拆文件。

在“OCR 设置”中可以调整并发上限：

- **默认 4**：最多同时处理 4 个分块，实际数量会根据电脑资源调整。
- **1–12**：自己设置最多同时处理多少个分块。
- **0**：交给软件自动选择，最多 12 个。

如果识别时电脑比较卡，可以改成 2 或 3。并发更高不一定更快，速度还取决于电脑性能和 PDF 内容。

界面会显示文件准备、OCR 和合并进度。准备完成后还需要等待识别与合并。需要取消时点击取消，正在进行的文件操作结束后会停止。

中途失败或取消后，保留软件文件夹中的 `.ocr-cache`，再对同一份 PDF 执行 OCR，可以复用仍然有效的分块和识别结果。

## 文件保存在哪里

| 文件 | 默认位置 |
| --- | --- |
| 整本 OCR PDF | 原文件旁，名称为 `原文件名_OCR.pdf`。 |
| 拆分后的章节 | `原文件名_章节拆分` 文件夹，也可以自己选择位置。 |
| 识别缓存 | 软件文件夹中的 `.ocr-cache`。 |
| 个人设置 | 软件文件夹中的 `umi-ocr.local.json`。 |

原始 PDF 保持不变。如果默认章节文件夹已存在，软件会另建带编号的文件夹。对同一份原文件重新完成 OCR 时，会更新同名的 OCR PDF。

即使 OCR 后没有识别出章节，整本 OCR PDF 也会保留，可以直接打开、搜索，或重新选择它进行分析。

## 主题和升级

在左侧“输出设置”中勾选“暗夜模式”即可切换主题，下次启动会记住选择。

升级时先关闭旧版，完整解压新版并从新版目录启动。需要保留原来的设置或继续 OCR 任务时，把 `umi-ocr.local.json` 和 `.ocr-cache` 一并保留；如果 Umi-OCR 路径变了，重新选择主程序即可。

## 常见问题

| 问题 | 可以这样处理 |
| --- | --- |
| 找不到 Python 或提示缺少依赖 | 确认 Python 已加入 PATH，并用启动软件的同一环境安装 `requirements.txt`。 |
| 连接不上 Umi-OCR | 检查是否完整解压、主程序路径是否正确，以及 HTTP 服务和端口是否一致。 |
| 识别进度暂时不动 | 看一下当前是否在准备文件或合并。大文件的这些步骤也需要时间；失败后可保留缓存重试。 |
| 没找到章节或标题不准确 | 核对 PDF 书签和文字，换一种检测方式，或手动补充章节后导出。 |
| PDF 有密码 | 先用密码解密，另存为未加密文件后再导入。 |
